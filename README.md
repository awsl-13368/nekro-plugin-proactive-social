# 主动消息 · 念头驱动社交引擎

> **她攒够了念头，会先开口。**
> 没说完的话，她记得回来问。
> 不只是定时器：什么时候开口、对谁开口、说什么，由念头和一件具体的事决定。
> 从 v4 起她还会**忍住**：累了不说，你忙就不闹，说多了会自己收着。

适配 [NekroAgent](https://github.com/KroMiose/nekro-agent) 2.x，OneBot v11 私聊。

---

## 它和普通"定时问候"有什么不同

| | 定时问候 | 本插件 |
|---|---|---|
| 触发 | 到点就发 | **念头攒满 + 必须有「由头」** |
| 内容 | 固定剧本 | 从真实对话、没说完的事、时间锚点里提取 |
| 自我否决 | 无 | 派不出由头 / 模型否决 / 硬闸 / 抑制层 → **不发** |
| 社交闭环 | 无 | 追问、接话、回访、收场、被无视就停、反省收敛 |
| 记忆 | 无 | 带权重、会衰减、会遗忘，回访按"最重"挑 |
| 分寸 | 无 | 累了会忍住；你忙就不推"想你" |

## 一次主动消息怎么走完

```
心跳醒来
  ↓
念头累积（默认 2 小时攒满，活跃度/周末缩放）
  ↓ 攒满
硬闸：安静时段？每日上限？刚聊过？停发期？
  ↓ 通过
找由头（5 级优先级）
  ├─ 1. 到期的未完话题（追问 / 接话 / 关怀）
  ├─ 2. 时间锚点（对方说过"明天""周末"）
  ├─ 3. 回访（加权记忆里最重要、还没结果的事）
  ├─ 4. 问候（早安 / 午间 / 晚安窗口）
  ├─ 5. 想念通道（关系够近）
  └─ 6. 生活场景兜底（38 个具体场景）
  ↓ 有由头
抑制层：太累了？对方在忙？刚反省过？→ 忍住（记一次，攒"执念"）
  ↓ 放行
模型闸门：这一刻该不该说？→ 可以否决
  ↓ 放行
交给 Agent 用人设说出来
  ↓
记账 → 1 小时后回看：有人接吗？没有就反省、收敛
```

**四条不发**：派不出由头、抑制层压住、模型否决、硬闸拦截 —— 都不发，念头留到下一轮。

## 核心机制

### 念头 + 由头
不是概率抽签。攒满念头只是"有资格开口"，还必须找到一件**具体的事**。找不到就不说。

### 抑制层（v4）
纯规则，不调模型，零额外成本：

| 条件 | 压住 |
|---|---|
| 疲惫 ≥ 阈值 | 想你 / 无聊 / 撒娇 / 问候 |
| 对方说过「累/加班/没睡」 | 12 小时内不推「想你」 |
| 刚反省过 | 24 小时收敛期 |

**执念**：同一种由头被压 3 次后，允许一次"实在憋不住"。
**重的事不受影响**：关怀、追问、时间锚点、收场照发。

### 记忆重量（v4）
```
大事（面试/生病/吵架/生日）1.8    日常 1.0    短应答 0.6    问句 0.9
14 天半衰期，权重 < 0.08 遗忘
回访按权重挑，不看时间——问"你上次面试"，不问"三天前天气不错"
```

### 事后反省（v4）
```
主动发完 60 分钟没人回 → 兴致 -12，记一笔
连续两次 → 24 小时收敛期：只挑重的事说
对方回了 → 兴致 +6，计数清零
```

### 兴致参与决策（v4.1）

`MOOD_ENABLED`（默认开）让「兴致」真正影响行为，不只是个数字：

| 兴致 | 行为 |
|---|---|
| ≤ `MOOD_LOW_THRESHOLD`（35） | 压住轻由头（想你/日常/问候）、不说琐事、语气变淡变短、不卖萌 |
| 35 ~ 75 | 一切照常 |
| ≥ `MOOD_HIGH_THRESHOLD`（75） | 允许多说两句、带点小雀跃 |

重的事不受影响：生病关怀、追问、时间锚点、收场照发。

### 社交闭环
| 机制 | 说明 |
|---|---|
| 追问 | 对方回得敷衍（「嗯/哦/好」）→ 过一会儿追问那件事 |
| 接话 | 她说完对方消失 → 补一句「你干啥去了」 |
| 回访 | 提过但没结果的事 → 2.5~14 小时后问后来 |
| 收场 | 发的一直没人接 → 自己冒一句收尾（最多 3 次） |
| 停发 | 连续 N 天不理 → 全面停发，等对方先开口 |

### 只做私聊
群消息**一律不看、不记、不触发**。

## 安装

1. 把 `proactive_social/` 整个目录放进 NekroAgent 的插件目录：
   ```
   <NEKRO_DATA_DIR>/plugins/packages/proactive_social/
   ```
2. **把插件加进配置里的启用列表**（这步最容易漏）：
   ```
   configs/nekro-agent.yaml
   PLUGIN_ENABLED:
     - ...
     - awsl_13368.proactive_social
   ```
   > ⚠️ 不加这一步，面板会显示"未启用"——此时**消息钩子和命令都不会注册**，
   > 只有调度器在跑。也可以直接在面板里点启用。
3. 重启 NekroAgent（或在面板里重载插件）

## 配置

面板 → 插件 → 主动消息 → 配置（全部有中文说明）。

### 最少改两项

| 配置 | 说明 |
|---|---|
| `CHAT_KEY` | 主动消息发到哪个私聊。填 `onebot_v11-private_<QQ号>`，或直接填 QQ 号（v4.1.1 起自动补全） |
| `QUIET_START` / `QUIET_END` | 安静时段，默认 `00:30` - `07:00` |

### 节奏

| 配置 | 默认 | 作用 |
|---|---|---|
| `ACTIVITY_LEVEL` | 75 | 念头涨得多快 |
| `URGE_REFILL_HOURS` | 4 | 多久攒满（越小越黏） |
| `MAX_SENDS_PER_DAY` | 8 | 每日上限 |
| `USER_COOLDOWN_MINUTES` | 30 | 两次之间最短间隔 |
| `RECENT_TALK_MINUTES` | 18 | 刚聊完多久内不另起话题 |
| `HEARTBEAT_MIN_MINUTES` / `..._MAX_...` | 8 / 30 | 心跳间隔（决定各项分钟级配置的精度） |
| `QUIET_END_WAKE` | `true` | 安静时段结束时补一次评估；心跳会截短到安静结束 |
| `CLOSER_ENABLED` / `CLOSER_AFTER_HOURS` | `true` / 8 | 她说完没人接，多久后自己收个尾 |
| `CLOSER_MAX_COUNT` | 3 | 最多收场几次 |
| `ADAPTIVE_REPLY_RATE` | `true` | 按回复率调整念头增速（回得少就说得少） |

### v4 拟真

| 配置 | 默认 |
|---|---|
| `SUPPRESS_ENABLED` | `true` |
| `SUPPRESS_TIRED_THRESHOLD` | 70 |
| `BUSY_QUIET_HOURS` | 12 |
| `OBSESSION_BREAK_THRESHOLD` | 3 |
| `MEMORY_HALF_LIFE_DAYS` | 14 |
| `MEMORY_MIN_WEIGHT` | 0.08 |
| `REFLECT_ENABLED` / `REFLECT_AFTER_MINUTES` | `true` / 60 |
| `MOOD_ENABLED` | `true` |
| `MOOD_LOW_THRESHOLD` | 35 |
| `MOOD_HIGH_THRESHOLD` | 75 |
| `RESTRAINT_HOURS` | 24 |

### 提示词时间（v4.1.1）

| 配置 | 默认 | 作用 |
|---|---|---|
| `PROMPT_TIME_MODE` | `clock` | 给由头/闸门里的对话加时间。`clock`=绝对时间（`[18:20]`）、`relative`=相对时间（`[3.7 小时前]`）、`off`=不加（与旧版一致） |

> 嫌太黏：`URGE_REFILL_HOURS` 调 6~8；嫌太安静：调 2~3。

## 命令（仅超级用户）

| 命令 | 作用 |
|---|---|
| `/proactive status` | 念头、今日计数、疲惫/兴致、记忆条数、未完话题、停发/收敛状态 |
| `/proactive dry` | **预览**此刻会说什么（不发送、不消耗） |
| `/proactive test` | 立刻真发一条 |
| `/proactive log` | 最近 8 条主动消息及由头 |
| `/proactive reset` | 重置念头、冷却、停发 |
| `/proactive on` / `off` | 运行时开关 |

## 数据

```
<plugin_data>/awsl_13368.proactive_social/state.json
```

存：念头、疲劳/兴致、未完话题、时间锚点、加权记忆、发送日志、反省计数。
状态文件是原子写入（临时文件 + `os.replace`），并保留 `state.json.bak`；
解析失败时优先回退备份，坏文件会改名成 `state.json.corrupt-<时间戳>` 留档。

## 兼容性

- NekroAgent 2.x（`/api/config/*` 体系）
- OneBot v11（`chat_key` 形如 `onebot_v11-private_xxx`）
- 无第三方依赖，只用 `pydantic` + NA 自带 `requests` 能力
- 思考型模型（如 gemini-flash 系列）需要 ≥200 tokens，代码里已限制

---

## 已知限制

- 抑制层的"疲惫"是模拟值，不接外部精力数据
- 记忆权重基于关键词判断，不是语义理解（避免额外模型开销）
- 记忆没有"已问过"标记，同一件事可能被回访多次

## 更新日志

### v4.2.0（当前）

**移除**

- 整个「群聊心流」模块：14 个 `GROUP_*` 配置、群内插话/破冰/起话头、群状态读写（约 260 行）
- 本插件只做私聊，群消息一律不看、不记、不触发；旧 `state.json` 里的 `groups` 残留会在加载时自动清掉

### v4.1.2（当前）

**修复**

- 模型闸门 / 回访跟随主程序的 `USE_MODEL_GROUP`（之前可能拿到一个挂掉的分组，导致"一条都不发"）；
  指定分组不可用时自动回退并只告警一次，`/proactive status` 会显示实际使用的分组与模型

**移除**

- 群聊样本采集（`GROUP_STORE_SAMPLES` / `GROUP_REF_SAMPLE_SIZE`）——原本只存不读，白占状态空间

### v4.1.1

**修复**

- `CHAT_KEY` 直接填 QQ 号不再静默失效：`tick` / `on_init` / `/proactive` 统一归一化，格式不对时只提示一次
- 记忆不再丢：消息钩子写入的记忆会被保留（之前会被 `tick` 的旧快照覆盖，记忆恒为 0 条）
- 状态文件改为原子写 + `state.json.bak` 备份，损坏时优先回退备份
- 收场计数与反省计数分离，被无视 3 次后收场不再永久失效
- `/proactive reset` 在未配置目标私聊时不再抛异常
- 疲惫会在安静时段恢复，单次推进封顶 60 分钟（之前只涨不落，几天后轻由头全被压住）
- 时间锚点：一句话只取一个锚点、时段映射到小时、"等会儿"=45 分钟、"下月/下下周"不再误判
- 否定词识别："今天不累""不忙"不再被判成在忙
- 短句不再一律算敷衍（"救命""别走"不会触发追问）
- 回复率真正影响念头增速（`ADAPTIVE_REPLY_RATE` 之前只有配置、没接线）
- 追问/接话改用"她最近一条发言"计时，不再只认主动消息
- 闸门改三态：模型无有效回复 → 否决；完全没配模型 → 视为关闭
- 静音结束更准时（心跳截短到 `QUIET_END + 60 秒`）
- `/proactive` 命令不再被当成"对方说话"
- 诊断日志只在 `DEBUG` 下输出
- 模型闸门/回访跟随主程序的 `USE_MODEL_GROUP`（之前可能拿到一个挂掉的分组），status 会显示实际分组

**新增**

- 由头 / 闸门 / 开口 prompt 带时间标记：`[18:20] TA: …`，跨天带日期
- 回访 prompt 带"现在是…"与时效约束：一次性小事超 2 小时别问，重要事可跨天
- 记忆条目标注年龄（今天 / 昨天 / N 天前）
- 配置项 `PROMPT_TIME_MODE`（`clock` / `relative` / `off`）
- 80 个单元测试（`tests/`，含最小 `nekro_stub.py` 桩）

### v4.1.0

- 兴致参与决策、抑制层、记忆重量、事后反省
